Curate Pipeline

Note: The curate Lambda runs as a separate deployment — not inside the Next.js app. Curation batches can exceed request/response timeouts; the Lambda uses chained invocation for continuation.

What It Does

Turns raw uploaded source files into structured wiki pages using Bedrock. The pipeline lives at infra/lambda/curate/ and supports two mode contracts:

Mode Contracts

Mode Event Version Output Path
Provenance 1 or 2 generated/<space>/<slug>.md
Folders 3 <destination>/<slug>.md

Pipeline Stages

  1. Reading — fetch source document from S3
  2. Extracting — Bedrock structures the content into sections
  3. Writing — emit the generated .md page to the destination
  4. Manifest — update _system/processed.json (CAS-protected)
