Architecture Overview

Layer Shape

Canopy is one Next.js app, not the two-service split the product spec originally planned: 

Browser → web/ (Next.js Route Handlers) → S3 (Markdown blobs) + Bedrock
Layer Location Responsibility
Pages web/app/ Server Components + Route Handlers
Logic web/lib/ S3 facade, search (Fuse.js), agent loop, auth, flags
Components web/components/ Interactive client components (sidebar, editor, chat)
AI Curation infra/lambda/curate/ Lambda deployment for long-running Bedrock curation

Why a Single App?

After Phase 2, the deployed architecture pivoted from two services (Next.js + FastAPI + Postgres) to the current single-app shape. Two concrete simplifications:

  • Search: Postgres FTS → in-memory Fuse.js index built from S3 listings
  • Metadata: Postgres document rows → Markdown frontmatter as canonical metadata
