What This Repository Does

Vaultmark is an S3-backed Markdown knowledge portal for individuals and engineering teams. It provides:

  • Portal — browse, search, edit Markdown from a Next.js UI
  • AI Curation — Lambda-powered Bedrock pipeline for content generation
  • Ask-Wiki Agent — conversational Bedrock agent with citations
  • Feature Flags — every feature individually toggleable

Quick Setup

# Install dependencies
pnpm install

# Set env vars
cp infra/.env.example web/.env.local

# Start the app
pnpm dev   # http://localhost:3000

Try It With No AWS

Run against the in-memory S3 mock — no credentials needed: 

pnpm dev:mock        # starts with MOCK_S3=1
pnpm seed:openwiki   # loads openwiki/ into the mock vault

Stack Overview

Layer Technology

Storage AWS S3 (Markdown blobs)
